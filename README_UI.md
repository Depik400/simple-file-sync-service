# File Sync - Terminal UI Mode

## Запуск с графическим интерфейсом

Для запуска File Sync с красивым терминальным интерфейсом используйте флаг `--ui`:

```bash
./file-sync config.yaml --ui
```

## Интерфейс

Интерфейс состоит из нескольких секций:

### Заголовок
Показывает версию и управление:
- **q** - выход
- **r** - обновить информацию

### Таблица активных загрузок
Отображает текущие загрузки файлов:
- **File** - имя файла
- **Server** - сервер-источник
- **Progress** - прогресс с визуальной полосой
- **Speed** - скорость загрузки
- **Status** - статус (downloading/completed/failed/paused)
- **ETA** - примерное время до завершения

### Таблица серверов
Показывает состояние peer-серверов:
- **Server** - имя сервера
- **Address** - адрес (host:port)
- **Status** - статус (online/offline/syncing)
- **Files** - количество файлов
- **Size** - общий размер файлов
- **Last Seen** - время последнего контакта

### Строка статуса
Отображает сводную информацию:
- Количество активных загрузок
- Общая скорость загрузки
- Количество онлайн серверов
- Общее количество файлов
- Общий размер файлов

## Особенности

- **Автоматическое обновление** каждую секунду
- **Цветовая индикация** статуса (зеленый - OK, красный - ошибка)
- **Визуальные прогресс-бары** для загрузок
- **Форматирование размеров** (B, KB, MB, GB)
- **Расчет ETA** на основе текущей скорости

## Сравнение с обычным режимом

| Обычный режим | UI режим |
|---------------|----------|
| Текстовые логи | Графический интерфейс |
| Сложно отслеживать прогресс | Визуализация в реальном времени |
| Много текста | Структурированная информация |
| Требует анализа логов | Интуитивно понятный интерфейс |

## Сочетания клавиш

- **q** - выход из программы
- **r** - принудительное обновление интерфейса

## Пример использования

```bash
# Запуск с UI
./file-sync examples/config-server1.yaml --ui

# В другом терминале запустить второй сервер
./file-sync examples/config-server2.yaml

# В третьем терминале запустить третий сервер
./file-sync examples/config-server3.yaml
```

После запуска серверов, добавьте файл в директорию одного из серверов и наблюдайте за синхронизацией в UI интерфейсе первого сервера.
